RIOT SWITCHER
=============

Change de compte League of Legends en un double-clic, sans retaper ton mot de passe.

- Aucun mot de passe n'est stocké : le script sauvegarde seulement la session
  "Rester connecté" créée par Riot, chiffrée avec ta session Windows
  (inutilisable si quelqu'un copie le dossier sur un autre PC).
- Le Riot Client n'est pas modifié et Vanguard n'est pas touché.
- Pour chaque compte : serveur, rang, évolution des LP, winrate, champions récents,
  sanctions, alerte de perte de LP, dernier lancement.
- Se met à jour tout seul (bouton bleu "Mettre à jour" quand une version sort).


INSTALLATION
------------
1. Extrais le dossier où tu veux (ex : Documents\RiotSwitcher).
   Ne le lance PAS depuis le zip, et ne le déplace plus après coup.
2. Double-clic sur "Creer raccourci bureau.bat" (facultatif).
3. Lance avec le raccourci "Riot Switcher" ou "Lancer RiotSwitcher.bat".

Si Windows affiche "Windows a protégé votre ordinateur" : Informations complémentaires > Exécuter quand même.


AJOUTER UN COMPTE
-----------------
1. Clique sur "Ajouter un compte" : le Riot Client s'ouvre déconnecté.
2. Connecte-toi en cochant "Rester connecté".
3. Lance League of Legends et attends l'accueil.
4. Le switcher détecte la connexion et te demande un nom de profil.
Recommence pour chaque compte.


UTILISATION
-----------
  Double-clic sur un compte       le lance (le client se ferme puis se relance dessus)
  Clic droit sur un compte        op.gg, graphique des LP, raccourci bureau, BAN, supprimer...
  Clic sur un en-tête de colonne  trie (re-clic = inverse)
  Rechercher / serveur / bannis   filtres en haut de la fenêtre
  Actualiser tous les comptes     lance chaque compte un par un pour tout mettre à jour
  Plus ▾                          export pour Discord, sauvegarde, thème sombre...

Réduire la fenêtre l'envoie près de l'horloge : clic droit sur l'icône = lancer un compte.
"Accepter les parties automatiquement" fonctionne tant que le switcher est ouvert.
"⚠ session à vérifier" = compte pas lancé depuis 3 semaines, la session a peut-être expiré :
connecte-toi dessus puis clic droit > "Ré-enregistrer la session".


MÊMES RÉGLAGES SUR TOUS LES COMPTES
-----------------------------------
1. Lance ton compte principal.
2. Clique sur "Copier mes réglages depuis le compte lancé" (touches, graphismes, son, interface).
3. Coche "Appliquer ces réglages à chaque lancement".


CHANGER DE PC
-------------
Les sessions chiffrées ne marchent que sur ce PC et cette session Windows.
Pour changer de PC : Plus ▾ > "Sauvegarder mes comptes..." (protégé par un mot de passe que tu choisis),
puis sur le nouveau PC : Plus ▾ > "Restaurer une sauvegarde...".


SÉCURITÉ
--------
Ne partage jamais le dossier "profiles" ni un fichier .rsbackup avec son mot de passe.
Pour partager l'outil, envoie seulement RiotSwitcher.ps1, les .bat et ce fichier.
